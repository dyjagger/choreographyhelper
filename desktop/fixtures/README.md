These synthetic fixtures exercise the real MP3 and MP4 decoders in the desktop playback regression. They contain a generated tone and a solid blue video; no user media is included. The WAV fixture is generated by the test itself.

Regenerate with FFmpeg:

```sh
ffmpeg -f lavfi -i sine=frequency=440:sample_rate=16000:duration=45 -ac 1 -b:a 24k -y playback.mp3
ffmpeg -f lavfi -i color=c=blue:s=64x64:d=3:r=10 -an -c:v libx264 -pix_fmt yuv420p -movflags +faststart -y reference.mp4
```
