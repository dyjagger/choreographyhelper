These synthetic fixtures exercise the real MP3 and MP4 decoders in the desktop playback regression. They contain generated stereo tones at 48 kHz (with album art) and 44.1 kHz, and a solid blue video; no user media is included. The WAV fixture is generated by the test itself.

Regenerate with FFmpeg:

```sh
ffmpeg -f lavfi -i color=c=blue:s=32x32 -frames:v 1 -y cover.jpg
ffmpeg -f lavfi -i sine=frequency=440:sample_rate=48000:duration=45 -i cover.jpg -map 0:a -map 1:v -c:a libmp3lame -ac 2 -b:a 128k -c:v copy -id3v2_version 3 -metadata:s:v title=Cover -metadata:s:v 'comment=Cover (front)' -y playback.mp3
ffmpeg -f lavfi -i sine=frequency=660:sample_rate=44100:duration=45 -ac 2 -b:a 192k -y replacement.mp3
ffmpeg -f lavfi -i color=c=blue:s=64x64:d=3:r=10 -an -c:v libx264 -pix_fmt yuv420p -movflags +faststart -y reference.mp4
```

The generated `cover.jpg` is only needed to rebuild the embedded album art and does not need to be committed.
