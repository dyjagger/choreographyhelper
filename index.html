How it works

  1. Add and select a dancer.
  2. Move the timeline to the desired time.
  3. Drag the dancer. Dropping it records that position.
  4. Add another position later, then press play.

Tip: selected dancers move with the arrow keys. Hold Shift for larger steps. Use Ctrl/Cmd+Z to undo.
